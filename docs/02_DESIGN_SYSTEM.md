# DESIGN SYSTEM
## Project Nawab

Version: 1.0

---

# Purpose

This document defines the complete visual identity of Project Nawab.

Every component in the application must follow these rules.

Never invent new styles unless approved.

---

• Premium

• Modern
• Luxurious

Never feel:

❌ Loud

❌ Flashy

❌ Cheap

❌ Template-based

❌ Corporate
